      Tips
      • Each fill color becomes one STL. Import them all into your slicer at once, as one multi-part object, and give each part a filament.
      • Only fills are used. Convert strokes first (Inkscape: Path › Stroke to Path).
      • Convert text to paths (Inkscape: Path › Object to Path).
      • Clipping paths and masks are not applied; release or apply them in your editor first.
      • Gradients use the color of their first stop.
      • Size comes from the SVG's physical size (mm, cm, in; px at 96 dpi), or set a width.
